1. CMY 与 RGB 三原色 三光色.

RGB是加色, 光线叠加越多越像白色靠近. 可以想成, 收集不同波段的光线, 波段集齐了就是白光.

加法滑块 = 光的强度

CMY是减色, 我们能看到颜色是因为那颜色光波不被物体所吸收, 所以是物体所反射的光. 白光反射所有的光波, 黑色吸收所有的光波.

减法滑块 = 颜料的浓度

此外还有一种记录颜色的模式是HSL,可以参考下面的椭圆体

拖左边任意一根，右边跟着动；反过来也一样。两组数字始终指向同一个色块——它们不是两种颜色，是同一个颜色的两种写法。

2. 三原色发现史:每一步都只对了一半

核心结论:三原色不是光的性质,而是人眼的性质。

年份 发现了什么 同时错在哪
1666 牛顿 白光是复合的;颜色不在光里,是一种感觉 硬凑成七色去对应音阶;认为每个波长同样基本,没得出「三」
1720s 勒布隆 三色套印可行;察觉颜料与光的方向相反 选了红黄蓝;说不出为什么,矛盾悬置一百年
1801 杨 视网膜不可能对应无穷波长,必然只有少数通道——推断是三种 纯推理,零证据;原色先猜红黄蓝,后改红绿紫,两次都不准
1850s 亥姆霍兹 加法与减法正式分家:颜料做减法,光做加法 三色理论解释不了残像,也说不清为何没有「偏红的绿」
1860s 赫林 补上对立过程理论,红-绿、蓝-黄成对拮抗 与三色说互斥了几十年,后来才知两者是视觉的前后两级
1861 麦克斯韦 色度可量化;拍出第一张彩色照片 当时乳剂对红光不敏感,红色底片本不该成像——1961 年才查明是紫外线撞了大运
1868 杜奥隆 提出 CMY,各自吃掉一个 RGB 通道 印刷业仍沿用红黄蓝几十年,色域白白窄了一截
1964 显微分光光度计首次测到三种视锥细胞 距杨的推理已隔 163 年

最大的错误其实是同一个: 从牛顿到勒布隆,所有人都在问「光里有什么」。杨把问题改成「眼睛能分辨什么」,答案才浮出来。

至于为什么偏偏是 R、G、B——通道数是眼睛定的,选哪三种光则纯属工程取舍:挑三个分得够开的波长,把色域三角形撑到最大。狗只有两种锥细胞,鸟有四种,它们的答案和我们完全不同。

3. Lightroom 调色的逻辑

先把最核心的一件事讲清楚,后面所有模块都是它的变奏。

一张照片,就是一大堆「三个数字」

屏幕上每个像素点,说到底只是三个数字:红多少、绿多少、蓝多少,每个从 0 到 255。

(255, 0, 0) 是纯红,(0, 0, 0) 是黑,(255, 255, 255) 是白。一张 2400 万像素的照片,就是 2400 万组这样的三个数字。

所以「修图」这件事,本质上只有一件事:按某种规则去改这三个数字。

而所有规则,归根到底只有三种基本玩法:记住这把万能钥匙:

三个数字的… 决定了 对应我们之前说的
平均高度 明暗 L 明度
最大和最小的差距 鲜艳程度 S 饱和度
谁大谁小的排序 是什么颜色 H 色相

差距为 0(三个数字一样大)就是灰色。这就是为什么灰色"没有颜色"——它三个通道完全相等,分不出谁多谁少。

下面每个模块,你都可以问一句:它在动哪一样?

管线

Lightroom 是非破坏性的,你调的每个滑块都只是往一张"指令单"上记一笔,真正渲染时按固定管线跑一遍。理解这个顺序,很多"为什么这个滑块要在那个滑块之前调"的经验法则就变成常识了:

Light 面板:让三个数字一起变

Exposure(曝光) —— 最简单的一个:三个数字同时乘同一个数。乘 2 就是亮一档,乘 0.5 就是暗一档。因为是同时乘,三者的比例不变,所以只变亮度、不变颜色。

Contrast(对比度) —— 规则是「本来就亮的变更亮,本来就暗的变更暗」。

这里有个副作用值得知道:加对比度会让颜色变艳。 为什么?因为一个偏红的像素 (180, 120, 90),红最大所以被推得更高,蓝最小所以被压得更低,三个数字的差距被拉开了——按上面那把钥匙,差距变大就是变艳。

Highlights / Shadows / Whites / Blacks —— 这四根是"分区域"的对比度。只管很亮的部分、只管很暗的部分,让你能分开处理。

Curve 曲线:精细版的明暗控制

曲线就是画一条"输入 → 输出"的对照表。横轴是原来的数字,纵轴是改完的数字。拉成 S 形,就是把亮的推更亮、暗的压更暗(也就是加对比度)。

有意思的是它还能分通道。单独抬高红色曲线的暗部,阴影就会带红——这就是"电影感调色"最常用的手法之一,本质只是把某个通道的某一段数字往上抬。

面板底下那根 Refine Saturation,就是用来抵消刚才说的"加对比度顺便变艳"这个副作用的。

① 主曲线(灰点)

它把同一条规则同时套给三个数字。

注意不是"只改亮度"——是 R、G、B 各自按这条曲线查表。所以拉成 S 形提高对比时,那个我们说过的副作用又来了:红多的像素红被推更高、蓝少的蓝被压更低,差距拉开 = 颜色变艳。

面板底下那根 Refine Saturation 就是给这件事擦屁股的。

②③④ 三条单通道曲线

**这才是真正调色的地方。**只动一个数字,直接改变了三个数的排序和差距——也就是色相和饱和度。

关键是每条曲线都是双向的,往下拉等于加它的互补色(接着上一条我们聊的互补关系):这里有个漂亮的呼应——蓝通道曲线就是 Temp 轴(蓝↔黄),绿通道曲线就是 Tint 轴(绿↔品红)。和白平衡完全一样的两个方向。

那区别在哪?

白平衡是全局的:整张图一起偏。曲线是分区域的:你可以让暗部偏蓝、亮部偏黄,同一张图里两个方向同时存在。

这就是"电影感"调色的全部秘密。经典做法:

蓝通道曲线,左端往上抬 + 右端往下压

结果是阴影带青蓝、高光带暖黄——模仿现实中阴影来自蓝天、高光来自太阳。

⑤ 参数曲线(波浪图标)

同样是主曲线,但换了操作方式:不给你自由拖点,改成四根滑块——高光 / 亮调 / 暗调 / 阴影。

点曲线 参数曲线
自由度 任意造型 只能温和起伏
风险 能拉出断层、色偏 几乎不会翻车
适合 明确知道要什么 快速试探

参数曲线在数学上被约束成平滑的,拉到极端也不会出现色带或诡异反转。新手用它更安全,而且两者可以叠加——先用参数曲线定大方向,再用点曲线抠细节。

最右边那个准星

取样调整工具。点开后,直接在照片上按住某处上下拖动,LR 会自动找到那个亮度对应曲线上的位置帮你调。

想压暗天空又不知道天空在曲线的哪一段?点它,在天空上往下拖就行。

三个立刻能用的手法

  1. 加对比 —— 主曲线拉 S 形。记得看一眼颜色是不是艳过头了。
  2. 褪色胶片感 —— 主曲线左下角的端点往上提。黑色不再是纯黑,画面像蒙了层灰。这是 Instagram 早期滤镜的核心动作,一步到位。
  3. 冷阴影暖高光 —— 蓝通道左抬右压,幅度要小,一两格就够。

第 2 个手法特别值得试,因为它用一个动作就说明了曲线的本质:你不是在"加滤镜",你是在改写"输入 0 应该输出多少"这条对照表。

白平衡:先把尺子校准

相机拍下的三个数字,受当时光线影响很大。同一张白纸,在黄昏的灯光下拍,红色数字会偏高;在阴天拍,蓝色数字会偏高。

白平衡做的事很简单:给三个数字各乘一个系数,让本该是白色的东西重新变回 (255, 255, 255)。

比如照片偏黄(红绿高、蓝低),就把蓝色数字乘 1.2、红色乘 0.9,拉回来。

界面上那两根滑块的颜色条已经把答案画出来了:Temp 是蓝↔黄,Tint 是绿↔品红。这两个方向正好能覆盖所有偏色情况。

为什么它必须第一个做? 因为它是在校准"尺子"。如果尺子本身是歪的,后面量什么都不准。

为什么 Temp 是蓝↔黄,Tint 是绿↔品红 覆盖所有偏色情况 # 核心结论先放前面 白平衡只用 Temp(蓝-黄) + Tint(绿-品红) 两个轴，不需要第三个独立轴，根源是： 人眼/相机色彩空间里，白平衡校正属于「色温相关的色偏」，落在二维平面上，不是完整三维RGB空间。 下面结合你熟悉的视锥、CIE、RGB通道逻辑一层层讲清楚。

1. 先厘清：白平衡到底在做什么运算

RAW白平衡本质： 给 R、G、B 三个通道各乘一个增益系数：

R′=kR⋅R,G′=kG⋅G,B′=kB⋅B R' = k_R\cdot R,\quad G' = k_G\cdot G,\quad B' = k_B\cdot B

目标：让中性灰物体反射光成像后 R’=G’=B’。

看起来明明是三个未知数 kR, kG, kBk_R,\, k_G,\, k_B，为什么只需要两个滑块控制？

因为存在一个约束：整体亮度缩放不影响色彩。

假设把三个增益同时乘以常数 ss：

(s kR, s kG, s kB) (s\,k_R,\ s\,k_G,\ s\,k_B)

只会让画面整体变亮或变暗，中性色彩平衡关系不变。所以三个增益里有一个维度是"白给"的：

3 个通道增益−1 个亮度维度=2 个独立色彩自由度 3\ \text{个通道增益} - 1\ \text{个亮度维度} = 2\ \text{个独立色彩自由度}

这就是数学上：3维向量空间，模长无关，方向只有二维自由度。

所以：校正中性色偏，理论上只需要两个控制维度。

2. Tint（色调/绿品轴）：绿色 ↔ 品红

垂直于黑体轨迹的正交轴，用来修正非黑体光源偏色：荧光灯、LED、水银灯，这类偏绿或偏品。

3. 为什么不选红↔青当第三根轴？

因为任何中性光源带来的色偏，都可以被这两组轴线性组合复现：

  • 偏橙 = 黄 + 少量品红
  • 偏青 = 蓝 + 少量绿
  • 偏紫 = 蓝 + 少量品红

所有现实场景下「灰色物体不再发灰」的色偏，全部落在这张二维平面内。 不存在一种中性色偏，无法用 Temp+Tint 组合模拟。

4. 举一个直观例子验证

场景：光源偏青色 青色 = 蓝偏多 + 轻微绿偏多 操作： Temp往黄拉（压低蓝色）+ Tint往品红拉（抵消绿色） 青色偏色直接校正完成。

场景：光源偏橙色 橙色 = 黄 + 品红 Temp往蓝抵消黄色，Tint往绿抵消品红。

任何全局光源色偏，都能分解到这组正交基底上。

5. 自然饱和度 vs 饱和度

两个都是「拉开差距」,区别在聪明程度。

  • Saturation —— 一视同仁,所有像素的差距都拉开同样比例。拉猛了,本来就鲜艳的红花会糊成一片死红。
  • Vibrance(自然饱和度) —— 会先看这个像素本来有多艳。已经很艳的少动,灰扑扑的多动。而且它特意避开肤色范围,免得把人脸拉成橙色。

拍人像用 Vibrance 更安全,就是这个原因。

Color Mixer:只找特定颜色下手

前面的操作都是全图统一。这个面板厉害在它会先看每个像素是什么颜色,再决定要不要动它。

八个色带(红橙黄绿水蓝蓝紫品红),对每一个都能单独调三样东西——正好是万能钥匙的三项:

  • Hue = 改排序 → 把绿色的树叶偏向黄一点
  • Saturation = 改差距 → 只让天空更蓝,不影响别的
  • Luminance = 改高度 → 只把红色压暗

这就是为什么拍风景常用它: 你想让天空更蓝,但不想让人的皮肤跟着变。全局饱和度做不到,这个面板可以。

顺带一提,八个色带的间距是不均匀的——红橙黄挤在很窄的范围里占了三个。因为肤色、夕阳、食物、木头全在暖色那一小段,值得多给几个精细档位。

怎么判断我要的颜色在哪个颜色的滑块? 如果比如说肤色的颜色掉在同时两种颜色的滑块, 我要怎么改?

最快的办法:用取样工具

就是 Color Mixer 面板右上角那个准星图标(我们之前在 Curve 面板也见过同一个)。

点亮它,然后在照片上你想改的地方按住往上下拖。Lightroom 会自己读出那个像素的色相,自动分配到对应的滑块上——横跨两个带的话,它会按权重同时动两根。

这是最可靠的方式,因为它绕过了"我以为这是橙色"这种主观判断。拖完回头看面板,就知道这个颜色归谁管了。

手动判断:看三个数的排序

如果想心里有数,规则很简单——看 R、G、B 谁最大、谁第二:

排序 色相区间 落在哪
R > G > B,且 G 接近 B 0°–20° 红
R > G > B,G 明显高于 B 20°–50° 橙(肤色在这)
R ≈ G > B 50°–70° 黄
G > R > B 70°–150° 绿
G ≈ B > R 150°–210° 水蓝
B > G > R 210°–260° 蓝
B > R > G 260°–310° 紫
R ≈ B > G 310°–350° 品红

判断口诀:最大的那个决定大方向,第二大的决定往哪偏。

比如典型的浅肤色 rgb(230, 180, 150):R 最大 → 红色方向;G(180) 明显高于 B(150) → 往黄偏。落在 20° 左右,橙带为主,红带为辅。

Color Grading:给亮部和暗部分别上色

三个色轮,分别管暗部、中间调、亮部。

色轮上转到哪个方向 = 加什么颜色,离圆心多远 = 加多少。这正是我们上次画的那个圆柱,横切下来的一片。

典型用法:暗部加一点蓝,亮部加一点橙。为什么好看?因为这模仿了现实——阴影里的光来自蓝色天空,高光来自暖色的太阳。很多电影都是这个配色。

blending 和 balance是啥, color grading 本质上是在亮部和暗部 增加其他颜色的滤镜吗?

Balance 和 Blending

这两根滑块管的是三个色轮各自的势力范围。

  • Balance = 分界线画在哪
  • Blending = 这条线有多模糊Balance 往右推,亮部的地盘扩大——更多像素被算作"高光",暗部被挤小。想让暖色扩散到更多区域时用它。

Blending 拉低,三块几乎不重叠,暗部的蓝和亮部的橙泾渭分明,可能在中间调出现生硬过渡。拉高则大面积渗透,颜色互相混合,过渡柔和但也更容易发浑。默认 50 是个稳妥的中间值。

第一条对,第二条差一点点——Blending 控制的是重叠宽度,不是距离。

区别在于:三个区域始终覆盖整个亮度范围,不会因为 Blending 低就"分开"、中间留出空隙。变的是交界处过渡得多突然:两边总跨度完全一样,没有谁离得更远。

换个比方可能更清楚——想象三盏聚光灯打在墙上:

  • Balance = 把灯往左右挪,决定光斑打在哪
  • Blending = 调焦,决定光斑边缘是刀切一样锐利,还是羽化开来

Blending 拉高时,墙上会出现大片"两盏灯都照到"的区域,那里两种颜色会真的混在一起。

实际后果:

好处 代价
Blending 低 暗部的蓝和亮部的橙互不干扰,对比强烈 中间调可能出现生硬色带
Blending 高 过渡自然 两个颜色互相稀释,效果变弱、容易发浑

所以更准确的说法是:

Balance = 分界线画在哪 Blending = 分界线有多模糊

一个管位置,一个管软硬。

是滤镜吗?——差不多,但有个关键区别

「在亮部和暗部加有色滤镜」这个理解方向是对的,但两端的运算其实不一样:

更像什么 数学上
暗部上色 打一盏有色补光灯 加法
亮部上色 镜头前加一片滤镜 乘法

这个区别有实际后果:给暗部上色容易让画面发灰。因为加法直接抬高了黑位——本来是纯黑的地方被加进了蓝光,就不再是纯黑了。这就是"褪色胶片感"的来源,想要就是优点,不想要就是脏。

而亮部是乘法,纯白乘任何颜色还是会保持明亮,所以给高光上色更"安全",不太会毁掉画面的通透感。

真正的物理滤镜只有乘法一种。所以严格说,Color Grading 比滤镜多了一种能力。

Calibration 不是"管其他光影部"的

这里要澄清一个维度问题:这两个面板切分画面的依据完全不同。

面板 按什么切 问的问题
Color Grading 亮度 这个像素有多亮?
Calibration 不切 (全局改原色定义)
Color Mixer 色相 这个像素是什么颜色?

Color Grading 管暗部/中间调/亮部,已经把亮度轴切完了——没有"其他光影部"留给别人。

Calibration 是另一根轴上的工具:它不看亮度,改的是"红绿蓝这三个字的含义",影响整张图的所有颜色。

打个比方: Color Grading 是分楼层刷漆(一楼刷蓝、三楼刷橙);Calibration 是换了一批不同色号的油漆桶,所有楼层同时受影响。

唯一的例外是 Calibration 顶上那个 Shadows Tint——它确实只管暗部。但它是个技术性补偿工具(修传感器在深暗部的色偏),不是创作工具,平时基本不用动。

那谁和 Color Grading 重叠?

是 Curve 的分通道曲线。两者都按亮度上色:

  • Color Grading —— 色轮直观,三个固定区域,适合快速定调
  • 分通道曲线 —— 任意多个控制点,精度更高,能做"只给 15%–25% 亮度那一段加青"这种精细活

先用 Color Grading 定大方向,再用曲线抠细节,是常见组合。

Color Calibration:改的是"红"这个字的定义

这个面板最难懂,但用我们的框架就好懂了。

前面所有操作,都是在改"数字"。这个面板改的是这些数字代表什么颜色。

打个比方:同样写「红」这个字,有的相机心目中的红偏橙,有的偏紫。这个面板就是去调整"红到底是哪个红"。三个滑块组分别对应红绿蓝三个原色的定义。

因为它动的是根基,所以拉一点点整张图就大变样。

这两个问题其实指向同一个结构。答案是:这三个面板做的是三种不同的数学运算,而它们修的是三种不同来源的误差。## 为什么 Shadows 要单拎出来

一句话:乘法修不了加法造成的误差。

传感器读数在完全没有光的时候也不是零,每个通道都有个微小的固定偏移(黑电平)。假设蓝通道的底噪偏移是 3、红是 1,那么在极暗的地方——信号本身只有个位数——这个差值就变成了肉眼可见的色偏。

关键在于:**这个偏移是常数,不随信号强弱变化。**而白平衡和相机校准都是乘法,乘法只会把偏移也一起放大,永远消不掉它。

所以必须有一个加法控件。它出现在 Calibration 面板里,不是因为它和原色定义是一类东西,而是因为两者都属于"修相机自身的毛病",在管线上处于同一个位置。

为什么只有绿-品红一个轴

这个细节挺妙的。相机传感器用的是 Bayer 阵列,每四个像素里有 两个绿、一个红、一个蓝。

绿色是两个采样点平均出来的,红蓝各只有一个。采样数不同,噪声统计特性就不同,在深暗部这个差异被放大,表现出来就是绿色和红蓝的分离——正好落在绿-品红轴上。

所以 Shadows Tint 只给了这一个方向,不是偷懒,是因为其他方向的偏差本来就不显著。

白平衡为什么不够

回到上面那张图。差别就在非对角线上的那六个数。

白平衡是对角矩阵,意味着红只影响红、绿只影响绿。它能做的事只有一件:把某一个颜色调成中性灰。

但把灰卡调准了,不代表红花就对了。

举个具体的例子:两台相机都把白纸拍成了标准白,但同一朵红玫瑰,A 相机拍出来偏橙,B 相机拍出来偏品红。这个差异白平衡永远修不了——因为要修它,你得让"红的输出里掺一点蓝",而对角矩阵的那个位置是 0。

自由度也说明问题:

自由度 能固定几个颜色
白平衡 2 一个(中性灰)
3×3 矩阵 6–8 整个色彩空间

白平衡像是把地图整体平移,让一个地标对上;满矩阵是旋转加拉伸,让所有地标都对上。

那为什么不合并成一个矩阵?

数学上完全可以——两个矩阵相乘就是一个矩阵。分开是工作流的需要:

  • 白平衡随每张照片变,取决于当时的光源。阴天一个值,室内白炽灯另一个值。
  • 相机校准随相机固定,是这台机器的物理特性,配置文件里存一次就够了。

合并了你就得每张照片重新校准一遍相机,那才是灾难。

所以完整的图景是:

加法修传感器 → 对角乘法修光源 → 满矩阵修相机 → 之后才轮到创作

三种运算各司其职,谁也替代不了谁。这也是为什么它们在管线里挤在最上游那一小段——全都是"还原真相"的工作,而不是"表达意图"的工作。

Effects

清晰度 / 去朦胧 / 纹理:要看邻居

这三个和前面所有模块有个本质区别:前面的操作只看当前像素自己,这三个要看周围的像素。

它们做的都是"局部对比":如果这个点比周围亮,就让它更亮;比周围暗,就让它更暗。结果是边缘和细节被强调出来。

区别只在"周围"的范围有多大:

  • Texture(纹理) —— 看很小的范围,处理细节,但刻意避开更细的噪点
  • Clarity(清晰度) —— 看较大的范围,加强中等尺度的层次。推太狠会出现边缘"光晕",就是范围没控制好
  • Dehaze(去朦胧) —— 专治雾霾。雾的特点是让所有像素的三个数字都往中间靠拢(差距变小、整体发白),所以去朦胧就是反过来把它们重新推开

晕影 + 颗粒:最后加的装饰

晕影 = 越靠近画面边缘,三个数字乘的系数越小(变暗)。用来把视线往中间引。

颗粒 = 给每个像素的数字加一点随机扰动,模拟胶片。

为什么必须是这个顺序?

三条理由,一条比一条重要。

① 先校准,再动手。 白平衡和相机校准是在确定"这些数字到底代表什么颜色"。这就像做实验前要先校准仪器——标准不对,后面所有测量都是错的。

② 先明暗,再颜色。 这条是硬约束。回想刚才那个副作用:改明暗会顺带改变饱和度(因为三个数字被拉开了)。所以顺序只能是:

先把明暗定下来 → 此时颜色已经被顺带改动了 → 再调颜色,把它修到你想要的样子

如果反过来,先精心调好颜色,再去动曝光和对比度,刚调好的颜色又会被破坏一遍,等于白做。这也是所有修图教程都说"先调曝光再调色"的真正原因——不是习惯,是数学上的先后依赖。

③ 装饰放最后。 晕影模拟的是镜头造成的暗角,颗粒模拟的是胶片本身的质感——它们都属于"拍摄时就存在的物理现象"。如果放在中间,后面的曲线会把晕影再加深一遍,锐化会把颗粒放大成噪点。放最后,才是干净的一层罩上去。

一句话总结整条管线:

先搞清楚数字代表什么颜色(白平衡) → 调整数字的整体高度(明暗) → 调整数字之间的差距和排序(颜色) → 最后加一层装饰(效果)。

所有面板、所有滑块,都只是在做这四件事之一。

5. 为什么lut盛行的时代, 还有人喜欢胶片

喜欢胶片的色彩, 好看, 一看就知道不是人能所调出来的, 是大自然, 神的给予. 那为什么人会喜欢胶片的感觉和色彩呢? 大自然的给予会给予万能的调色公式吗? 还是胶片的色彩会满足一些色彩互补 同一药水 温度色差 更完美? 胶片色彩符合一些黄金比例吗?

两个问题都很好,而且它们的答案其实是同一个。先分开说,最后合起来。

4. 有没有万能公式

数学上就不可能

预设是一组固定的参数偏移。同一个偏移作用在不同起点上,结果必然不同——一张欠曝的阴天照和一张顺光的正午照,加同样的 +0.3 曝光、−28 对比,一个救活了一个毁了。

这不是预设做得不够好,是预设这个形式本身的天花板。

但确实有接近万能的东西:记忆色

人对三种颜色有极强的内在参照:

记忆色 大致色相 偏离的后果
肤色 20°–28° 偏绿显病态,偏品红显廉价
天空 210°–230° 偏青显假,偏紫显廉价
植物 90°–120° 偏黄显枯,偏青显塑料

这三个是负向规则——不是"调到这里就好看",而是"偏离了一定难看"。人眼对这三样东西的判断几乎不需要参照物,因为脑子里存着一辈子的样本。

所以真正接近万能的不是配方,是警戒线。

和谐的可靠手段:做减法

如果要说有什么规律,最可靠的一条是:限制比自由更容易产生和谐。

画面里颜色种类越少,越容易显得"是设计过的"。具体做法:

  • 把杂色往主色相靠(比如让所有绿都偏同一个方向)
  • 压低次要区域的饱和度,只留主体鲜艳
  • 给整张图加一个统一的色偏(哪怕很轻微)

这几条之所以有效,原因和你问题里的"胶片"是同一个——统一性。下面会说到。

橙青:最接近"万能公式"的东西

肤色在 20° 左右,它的互补色在 200° 左右,正好是青蓝。所以「暖肤色 + 冷背景」能最大化主体与背景的分离,这是有理论依据的。

好莱坞把它用成了标配。然后——它成了陈词滥调。

这件事本身就回答了你的问题:**一个真正万能的公式,一旦万能,就不再有价值。**公式能保证及格,不能给你出色。

最强的调色发生在按快门之前

你提到"衣服配色的逻辑"——这一点特别重要,而且常被低估。

**选择拍什么、穿什么、在哪拍,比后期强大得多。**一件荧光粉的外套,后期没有任何办法让它和谐;而一开始就让人穿灰蓝色站在砖墙前,你几乎不用调色。

后期能做的是"强化已有的关系",做不到"无中生有"。

5. 为什么还有人爱胶片

先纠正一个前提

胶片的色彩恰恰不是自然的给予,而是人类历史上最重工程化的色彩系统之一。

柯达为了 Portra 的肤色调了几十年配方,Velvia 是为了风光刻意做高饱和的商业决策。每一款胶片的色彩性格,背后都是化学家、市场部和无数次试片。它比任何 LUT 都更"人造"。

但它感觉自然。这个错觉值得拆开看。

原因一:高光不会被一刀切

数码传感器到了满值就是满值,再多的光都记录成同一个数。胶片是化学反应,越接近饱和反应越慢,形成一个渐进的肩部:这条肩部曲线,恰好和人眼对亮度的压缩响应很像。所以胶片的高光看起来"对",不是因为它准确,而是因为它错得和眼睛一样。

原因二:三层药膜是耦合的

这是最难复制的一点。

胶片的红绿蓝三层不是独立工作的,显影时一层的反应会抑制相邻层(专业上叫 DIR 耦合剂)。结果是:色相偏移会随密度变化——暗部偏一个方向,亮部偏另一个方向,中间连续过渡。

数码的曲线是三条独立的查找表,通道之间没有这种串扰。你可以用曲线硬凑一个近似,但那是三条各自为政的线,不是一个耦合系统。

原因三:人们爱的是工程师想消除的东西

这是全部里最妙的一点。

胶片三层的特性曲线没法做到完全一致,于是在不同密度下三层的平衡会漂移——这个现象叫交叉(crossover),当年被视为缺陷,柯达花了大力气去压制它。

而残留下来那一点点交叉,表现出来就是:暗部偏冷、亮部偏暖。

也就是今天所有人都在追的那个"电影感"。

所以回答你的问题:**Portra 的冷暗部暖亮部确实接近互补分离,但它不是从色彩理论推导出来的,而是化学缺陷没修干净的残余。**人们后来才反过来给它编织了理论。

关于黄金比例

没有。

胶片色彩和黄金比例没有任何关系。这是一种常见的思维模式——凡是被推崇的东西,总有人回头去找黄金比例。找得到的多半是硬凑,找不到的就换个指标继续找。

胶片的曲线形状来自银盐晶体的化学动力学,以及柯达市场部对肤色的商业判断。前者是物理,后者是品味,都不是数学常数。

原因四:一整卷用同一条曲线

这一条最重要,而且直接回答了你的第 4 问。

一卷胶片 36 张,全部经过同一个色彩变换。晴天阴天、室内室外、人像风景,都被同一条曲线碾过一遍。

结果是天然的统一性——不是因为那条曲线特别正确,而是因为它对所有照片一视同仁。

数码给了你无限自由,而自由不产生统一。你可以每张照片调得更"对",但一组照片放在一起就是散的。

把两个问题合起来

和谐来自约束,不来自正确的参数。

  • 预设失败,是因为它给的是参数——参数遇到不同起点就崩。
  • 胶片成功,是因为它给的是约束——一个你无法逃脱的、统一施加于一切的限制。

这也解释了为什么职业摄影师往往只用两三种胶片、或者只用自己那一套 LUT。不是因为找到了最优解,是因为放弃选择本身就是一种风格。

LUT 复制不了的那一半

最后说 LUT 的局限。LUT 是一张静态的 RGB→RGB 映射表,它能相当好地复制胶片的颜色映射。但它复制不了:

  • 颗粒的结构——胶片颗粒是随机银盐晶体,尺寸随密度变化;数码噪点是逐像素的,性质完全不同
  • 光晕(halation)——强光穿透药膜从片基背面反射回来,在高光边缘形成红晕
  • 最关键的:捕捉阶段——数码高光一旦削平,任何 LUT 都救不回来。胶片的魔法有一半发生在按快门的那一刻,不在后期。

这就是为什么套了胶片 LUT 的数码照片,常常"像但不是"。像的是映射那一半,缺的是捕捉那一半。

如果要给一句实操建议:

别找万能公式,给自己定一套约束。选三种色调,一个固定的对比曲线,一个统一的暗部色偏,然后逼自己所有照片都用它。三个月后你会有风格——不是因为那套参数好,而是因为你坚持了。

我说明的第一条是 把所有照片都拉到一个中性亮度和色彩, 在套用统一的preset, 有这种preset吗? 以及那些互补色, 中性色调, 衣服颜色搭配的风格投入到照片里也会给人漂亮的感觉 这种修图思路. 我在寻找人类可能喜欢的调色模式

你这个补充很关键——先归一化,再套统一 preset,这正好绕开了我上一条说的问题。我说"预设必然失败",前提是每张照片起点不同;你加了归一化这一步,起点就统一了。

这不是权宜之计,这就是电影行业的标准流程。

这套流程叫什么

在调色行业里它有明确的名字:

步骤 行业术语 做什么
① 归一化 Primary / Balance 白平衡、曝光拉到统一基准
② 局部修正 Secondary 蒙版、特定颜色
③ 统一风格 Look / LUT 全片一套,不再逐镜头调

**第三步之所以能"一套用到底",完全依赖第一步做得干净。**归一化没做好,后面的 look 就会在不同镜头上呈现出不同结果——这正是预设在业余流程里失效的原因。

怎么可靠地归一化

最硬的办法:拍色卡。

现场用同一光线拍一张 ColorChecker(百来块的护照式色卡),回来在 Lightroom 里:

  1. 用它生成一个自定义相机配置文件
  2. 这个配置文件套到同一场景的所有照片上
  3. 此时所有照片的色彩基准在数学上真正对齐了

这一步做完,你的 preset 才有可能真正"通用"。没有色卡的话,退而求其次:

  • 灰点吸管点画面里本该中性的东西(白墙、灰路面、白衣服的阴影面)
  • Lightroom Classic 有个 Match Total Exposures,选中一组照片能把曝光拉齐
  • 肤色作为锚点:让脸的色相落在 20°–28°

**三个锚点的优先级:中灰 > 肤色 > 白点。**有人的照片以肤色为准,没人的以中灰为准。

那么,人类普遍喜欢什么调色?

这是你真正在问的问题。有答案,而且不神秘——大部分"好看"的调色模式,都是在模仿自然光的物理规律。

规律一:暖高光 + 冷暗部

这条最深,而且是物理事实,不是审美偏好。

户外有两个光源:

  • 太阳 —— 直射光,约 5500K,偏暖
  • 天空 —— 蓝色穹顶,给阴影补光,约 10000K,偏冷

所以在真实的日光下,亮的地方本来就比暗的地方暖。这是我们这个物种睁眼看了几十万年的东西。

调色时顺着它做(暗部加青蓝、亮部加橙黄),画面读起来"自然";反过来做(暖阴影、冷高光),会产生说不清的不安感——恐怖片和惊悚片经常故意这么干。

这就是 Color Grading 面板最经典用法的来源。它不是好莱坞发明的风格,是日光的物理结构。

规律二:远处更淡、更冷

大气透视:空气会散射光线,越远的东西饱和度越低、越偏蓝、对比越弱。

人脑把这个当作深度线索。所以后期把背景降饱和、加一点冷调,画面会立刻"有空间感"——因为你在给大脑喂它熟悉的信号。

这条特别实用:主体保饱和,背景压饱和,几乎不会出错。

规律三:记忆色不能越界

肤色、天空、植物。人对这三样有终身校准的内在参照,偏了立刻能察觉,哪怕说不出哪里不对。

这是唯一真正接近"硬规则"的一条。

规律四:蓝色确实占便宜

关于颜色偏好,心理学上有个叫生态效价理论的解释(Palmer 和 Schloss 的研究):人对某个颜色的喜好,约等于对"这个颜色的常见事物"的喜好加权平均。

  • 蓝 → 晴空、清水 → 跨文化最受欢迎
  • 青绿 → 植被、海 → 也很讨喜
  • 暗黄绿/橄榄 → 腐烂、排泄物 → 最不受欢迎

所以你直觉里的"多绿色蓝色"是有依据的,但要精确一点:**受欢迎的是蓝和青绿,不是黄绿。**同样是绿,往蓝偏讨喜,往黄偏就危险。

这也解释了为什么调色时把绿色往青蓝方向推(降低黄绿),画面往往立刻变高级。

为什么这些规律有效

心理学里有个概念叫加工流畅性:大脑处理起来越省力的东西,越容易被判断为"美"。

符合自然统计规律的图像,视觉系统处理起来最省力——因为它就是为解析这类图像进化出来的。

还有个漂亮的呼应:自然场景的颜色分布,主要沿着蓝-黄方向展开(因为日光一天里就是在这个方向变化)。而我们眼睛的对立通道也正好是蓝-黄。而 Lightroom 的 Temp 轴还是蓝-黄。

**光源的变化方向、眼睛的编码方向、软件的控制方向,三者重合。**这不是巧合,是层层适配的结果。

一个可操作的"通用底子"

如果要一个真的相对普适的起点,我会这样组:

归一化之后 ——

Color Grading
  Shadows    ← 加一点青蓝，饱和度极低（5–10）
  Highlights ← 加一点橙黄，饱和度极低（5–10）
  Blending   50，Balance 0

Color Mixer
  Green      色相往青偏（+10 左右），饱和度 −10
  Aqua/Blue  饱和度 +10~15
  Orange     几乎不动（保肤色）

Curve
  轻微 S 形，左下端点抬起 2–5（一点点褪色）

为什么这几条是这样:

  • 冷暗暖亮 = 规律一
  • 绿往青偏、降饱和 = 规律四(躲开黄绿)
  • 蓝青提饱和 = 规律四(往讨喜方向去)
  • 橙不动 = 规律三(保肤色)
  • 端点抬起 = 模仿胶片的趾部,顺带柔化

这套东西不会让照片惊艳,但会让一组照片看起来是一组。它的价值在统一,不在出彩。

最后一句诚实的话: 这些规律能让你稳定地做到"耐看",做不到"难忘"。难忘来自内容——光线的时机、人的表情、构图的取舍。调色是把已有的东西擦亮,不是把没有的东西变出来。

但先做到稳定的耐看,已经能筛掉九成的照片了。
